# SQ Hub Vision

**Status:** ACCEPTED

## Vision
SQ Hub adalah shared digital platform foundation untuk ekosistem sistem informasi Sabilul Qur'an.

SQ Hub menyediakan fondasi lintas aplikasi sehingga staf dapat menggunakan berbagai sistem dengan identitas yang sama, struktur organisasi yang konsisten, kontrol akses aplikasi yang terpusat, dan pengalaman antarmuka yang senada.

## SQ Hub is
- fondasi identitas staf dan Single Sign-On;
- master Organizational Unit;
- registry aplikasi dan Application Access;
- shared design system dan app-shell conventions;
- tempat shared capability lintas aplikasi bila kebutuhan nyata terbukti;
- titik integrasi yang memungkinkan aplikasi tetap independen tetapi interoperable.

## SQ Hub is not
- ERP monolith;
- tempat business logic HCIS, SPMB, Finance, Workspace, Academic, atau aplikasi domain lain;
- satu universal database untuk semua business domain;
- universal Person Registry pada fase awal;
- alasan untuk membuat microservice atau abstraction sebelum ada kebutuhan nyata.

## Product principles
1. One staff identity, many applications.
2. Clear data ownership, strong integration.
3. Shared only when truly shared.
4. Domain applications remain independently maintainable.
5. Consistent experience across applications.
6. Security-sensitive behavior is explicit, testable, and never invented by AI.
7. Documentation and contracts precede implementation.

## Initial ecosystem
- SQ Hub
- HCIS
- SPMB

Future applications may include Finance, Workspace, Academic, Asset, and other systems when justified by actual needs.
